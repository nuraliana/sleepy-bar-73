One sharp, funny loading-screen tip for stressed developers and AI coding
agents, in a single line of at most 200 characters.

The tip, written by `main.py` to `entry.txt`:

> Tip: your agent's six-step plan starts with 'understand the codebase.' It's still on step one. So are you.

Run it with `python3 main.py`. It writes `entry.txt` inside the directory
named by `MAKEFUN_OUTPUT_DIR` when set, and next to `main.py` otherwise.
Standard library only; the output is the same on every run.

A loading screen is dead air, so this entry fills it with a joke every coder recognises at once.
It teases the agent that promises a grand plan and then stalls on step one — the same wait the reader is stuck in.
